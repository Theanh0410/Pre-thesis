# Phân phối tác vụ trong hệ thống đa tác tử (multi-agent system)

Trong nhà thông minh, các tác tử (agents) có thể đóng vai trò như:

- Agent ánh sáng (LightAgent)
- Agent điều hòa (ClimateAgent)
- Agent an ninh (SecurityAgent)

Mỗi agent có thể nhận nhiệm vụ cụ thể dựa trên khả năng của mình. Task Allocation được thực hiện theo 3 mô hình chính:

1. **Centralized (tập trung):** Một server trung tâm quyết định ai làm gì.
2. **Distributed (phân tán):** Mỗi agent tự đưa ra quyết định dựa trên thông tin chia sẻ.
3. **Market-based (thị trường):** Các agent đấu giá hoặc thương lượng để nhận nhiệm vụ.

Ví dụ, khi có sự kiện "có người về nhà", hệ thống MAS sẽ phân phối:
- LightAgent bật đèn phù hợp
- ClimateAgent bật điều hòa theo lịch trình
- SecurityAgent tạm ngưng chế độ báo động
